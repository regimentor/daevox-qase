# Изменяемая ширина блока suites без перекрытия таблицы

Status: done
Owner: Codex

## Problem

В репозитории тест-кейсов блок suites можно растягивать, но ширина первой колонки layout ограничена 280 px, а сам блок может расширяться до 420 px. В результате он выходит за границы своей колонки и перекрывает правый блок с метаданными suite и таблицей. Названия suites обрезаются через ellipsis.

Пользователь хочет сохранить изменение ширины блока suites: при его расширении правая часть должна уменьшаться, а таблица — переходить в горизонтальную прокрутку внутри своего контейнера.

## Scope

- Связать ширину первой колонки layout с фактической шириной блока suites.
- Сохранить возможность растягивания блока suites по горизонтали.
- Ограничить растягивание доступным местом, оставляя правой части полезную минимальную ширину.
- Обеспечить горизонтальную прокрутку таблицы внутри её контейнера.
- Показывать полные названия suites с переносом длинных строк.
- Сохранить вертикальную компоновку на узких экранах.

Изменения ограничены frontend layout и отображением дерева suites. GraphQL, API, хранение данных и доменные контракты не меняются. Сохранение выбранной ширины между посещениями не входит в задачу.

## Acceptance criteria

- [x] На широком экране пользователь может расширять и сужать блок suites по горизонтали.
- [x] Начальная ширина блока — 280 px, минимальная — 240 px; размеры учитывают padding и border.
- [x] Максимальная ширина зависит от ширины контейнера: справа остаётся не менее 320 px с учётом промежутка между колонками.
- [x] При расширении suites правая часть с фильтрами, метаданными и таблицей уменьшается; блоки не перекрывают друг друга.
- [x] При уменьшении доступной ширины окна ранее растянутый блок автоматически ограничивается текущим доступным местом.
- [x] Если таблица не помещается по ширине, её столбцы доступны через горизонтальный скролл внутри таблицы; страница не расширяется по горизонтали из-за таблицы.
- [x] Фильтры, поля предусловий/постусловий и кнопки остаются внутри правого блока и при необходимости переносятся.
- [x] Длинные названия suites, включая строки без пробелов и вложенные suites, видны полностью через перенос; меню действий остаётся доступным.
- [x] При ширине viewport до 1023 px включительно suites расположены над правым блоком, растягивание отключено, оба блока помещаются в контейнер.
- [x] Проверка в браузере или Storybook покрывает растягивание, сужение окна после растягивания, длинные названия и внутреннюю прокрутку таблицы.
- [x] Выполнены frontend проверки; результаты и возможные блокеры записаны в Implementation notes.

## Implementation notes

Реализовано в ветке `fix/issue-2-resizable-suite-panel` после подтверждения пользователя.

- Layout переведён на flex: фактическая ширина suites уменьшает доступную ширину правой части.
- Начальная ширина suites — 280 px, минимальная — 240 px, максимальная — `calc(100% - 330px)`; 330 px учитывает 320 px правой части и gap 10 px.
- Существующая прокрутка Ant Design Table сохранена. Названия suites переносятся, включая длинные слова и вложенные узлы.
- Поля метаданных адаптируются к ширине правой части; длинный заголовок метаданных и кнопки заголовка страницы переносятся.
- На viewport до 1023 px ширина suites сбрасывается, включая inline width от native resize; блоки расположены вертикально.
- Обновлён `frontend/web/CONTEXT.md`; добавлен Storybook-сценарий layout и обновлена проверка переноса названий.
